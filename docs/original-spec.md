# Lumenfall: Shardfront
Genre: original colorful 3D third-person arena action roguelite.
Core: Solo instanced-by-owner runs in a shared alien arena. Begin from title; 3 waves of 4/6/8 enemies. Wave 1 skitter beetles, wave 2 adds ranged floating spores, wave 3 both; after wave 3 a giant Rift Warden boss. Aim in camera direction and fire with mouse click / touch FIRE / gamepad R2; E / touch BURST / gamepad B emits a short-range pulse with cooldown. Enemies chase/strafe and hit on intervals; spores fire dodgeable visible bolts. Boss approaches and launches a radial telegraphed pulse. Running out of HP loses. Clearing boss wins. Between waves choose exactly one of 3 deterministic upgrades: +max HP and heal, +damage, or +move speed. Run reset clears run upgrades and enemies. Each ended run awards shards equal to waves cleared + boss bonus, saved server-side; spend 5 shards per permanent Vitality rank, cap 5, +10 starting HP per rank. Save best wave too. No Robux.
Content: one sculpted alien ring arena; 2 distinct generated enemy models and one generated boss, 3 waves and boss; crystal growths, luminous rings, ruins, sky. Palette deep indigo, teal, coral, gold; atmospheric sunset lighting. Default avatar gets glowing aura accent. Generated mesh cast; constructed arena/scenery and projectile particles. Game feel includes eased enemy bob/turn, neon shot trails, impact flash, sound and gentle camera punch.
UI: safe-inset title with start, persistent progress and permanent upgrade button; gameplay HUD for HP, wave, kills, shards, boss HP and crosshair, contextual upgrade selection overlay; win/lose summary and replay. On narrow phones the large central overlays constrain width and scroll as needed; HUD is top and combat buttons at lower right above default jump; default movement thumbstick and jump retained. Keyboard WASD, space, mouse to aim/fire, E pulse; mobile touch FIRE/BURST, gamepad R2/B.
Architecture: server modules own sessions, enemy simulation, damage, wave state, persistence and all rewards; thin server entry owns player and remote connections; client entry owns interface, camera/UI feedback and input. Workspace folders Arena, EnemyVisuals, Projectiles. No unsafe dynamic code or text input.
Acceptance: Start button enters wave 1 with 4 enemies and active HUD. Shoot aimed target lowers enemy health then kills it; fire cannot hit beyond range or faster than cooldown. Pulse hits nearby targets with cooldown. Spores shoot dodgeable projectile and beetles chase/contact attack. Kill all enemies advances to upgrade screen; choose one and see corresponding stat change before next wave. Wave 2 has 6 mixed and wave 3 has 8 mixed, boss appears after third upgrade and can be damaged/defeated. HP zero shows defeat; boss zero shows victory; replay starts clean. Summary awards shards, permanent rank purchase deducts exactly 5 and persists with best wave; no other player can control a run. Inputs on mouse/touch/gamepad remain accessible. Verify by inspecting construction/readback, compile, isolated module scenario tests and finalization, and runtime client where available. Art models, lighting, shot effects, overlays and music/SFX present.

# Initial build contract
Build Lumenfall: Shardfront as a complete 3D solo arena roguelite with 3 waves (4,6,8), two behaviorally distinct enemies and a boss. Start/title, safe HUD, choose exactly one of 3 upgrades after each wave, win/lose summary and replay. Third choice starts boss. Server authoritative shooting along camera direction with distance/cone validation and cooldown, close pulse cooldown, periodic enemy contact/ranged damage, boss attack and HP. Permanent shards awarded on run end, 5-shard Vitality ranks up to 5 with persistent shards/best/rank; run modifiers reset on replay. Server saves and handles errors without blocking play. Enemies only owned by corresponding player; remotes validate owner and phase. Original alien art models for three enemy roles, luminous hand-built arena, avatar glow, VFX, music and event SFX. Default movement/jump plus mouse/touch/gamepad actions. Requirements checks: entering run spawns wave and HUD; firing decreases target HP; all kills transition choice; chosen stat changes; boss defeat wins; dying loses; replay resets; rank buy spends shards and rank persists; client UI parents and usable; static compilation, finalization, isolated server tests pass. Non-goals: multiplayer cooperative combat, procedural map generation, Robux economy, inventory trading.
